# Подключение к ChatGPT

Сервер поддерживает MCP через SSE. Для подключения из ChatGPT он должен быть доступен по HTTPS из интернета либо через Secure MCP Tunnel. Адрес локального компьютера вида `http://localhost:8001/sse` ChatGPT напрямую не увидит.

## Доступность

По актуальной документации OpenAI, пользовательские MCP-подключения доступны в ChatGPT Business и Enterprise/Edu на веб-платформе. В ChatGPT Pro поддерживается подключение пользовательских MCP-серверов с разрешениями только на чтение. Доступность зависит от плана, прав администратора и настроек рабочего пространства; на Free/Plus это подключение может быть недоступно.

## Подготовить сервер

Запустите проект через Docker и настройте токен WB в разделе магазинов:

```bash
docker compose up -d --build
```

Проверьте локально:

```bash
curl http://localhost:8001/api/health
```

Задайте `MCP_AUTH_TOKEN` в `.env` и перезапустите контейнер. Не публикуйте MCP endpoint без аутентификации. Для удалённого доступа используйте HTTPS reverse proxy либо Secure MCP Tunnel. Не открывайте порт сервера всему интернету без TLS и контроля доступа.

## Добавить подключение в ChatGPT

Откройте ChatGPT в браузере и перейдите в **Plugins / Apps** (название раздела зависит от текущего интерфейса и типа рабочего пространства). Выберите добавление пользовательского MCP-сервера.

Укажите имя, например `Wildberries Read Only`, и HTTPS URL MCP endpoint:

```text
https://YOUR-DOMAIN/sse
```

Если используете Secure MCP Tunnel, выберите подключение через Tunnel и укажите выданный `tunnel_id`. Настройте способ аутентификации, если он поддерживается выбранным способом подключения. Завершите создание и просмотрите список обнаруженных инструментов.

После подключения проверьте запросом: «Покажи список моих магазинов Wildberries». Затем запросите данные, например продажи за период или список активных рекламных кампаний.

## Границы доступа

Сервер публикует только инструменты чтения. Однако чтение может возвращать коммерчески чувствительные сведения: продажи, финансы, заказы, клиентские данные, рекламные показатели и документы. Подключайте его только к доверенному аккаунту ChatGPT и учитывайте политики хранения и обработки данных вашего рабочего пространства.

Если ChatGPT не принимает endpoint, проверьте доступность HTTPS снаружи, сертификат TLS, авторизацию и совместимость SSE. В текущей версии сервер использует SSE; для клиентов, требующих Streamable HTTP, потребуется отдельная поддержка этого транспорта.
